# 게임 프레임워크 PRD

## 1. 목표

게임 모드 전환과 아이템 선택 기능을 갖춘 기본 게임 프레임워크를 구현한다.

## 2. 기능 요구사항

### 2.1 게임 모드

- 로고 모드는 일정 시간 동안 로고를 표시한 뒤 타이틀 모드로 전환한다.
- 타이틀 모드는 `title.png`를 표시한다.
- 타이틀 모드에서 `SPACE`를 누르면 플레이 모드로 전환한다.
- 타이틀 모드에서 `ESC`를 누르면 게임을 종료한다.
- 플레이 모드에서 `ESC`를 누르면 타이틀 모드로 돌아간다.

### 2.2 정지 모드

- 플레이 모드에서 `P`를 누르면 정지 모드로 전환한다.
- 정지 중에는 게임 월드의 업데이트를 멈춘다.
- 정지 모드에서 `P`를 누르면 플레이 모드로 돌아간다.

### 2.3 아이템 모드

- 플레이 모드에서 `I`를 누르면 아이템 모드를 오버레이로 표시한다.
- 아이템 모드에서도 플레이 모드의 게임 월드는 계속 업데이트된다.
- 아이템 모드에서 `I`를 누르면 플레이 모드로 돌아간다.
- 아이템 모드의 안내 이미지에 따라 다음 명령을 제공한다.
  - `0`: 기존 공을 제거하고 공 발사를 비활성화한다.
  - `1`: 작은 공을 선택한다.
  - `2`: 큰 공을 선택한다.
- `1` 또는 `2`로 공을 선택한 뒤 `SPACE`를 누르면 선택한 공을 발사한다.

## 3. 구현 원칙

- 모드 전환은 `game_framework`의 모드 스택을 사용한다.
- 아이템 모드는 플레이 모드의 업데이트와 게임 화면을 재사용한다.
- 공의 이미지 종류는 발사 시점에 선택된 설정을 사용한다.

## 4. 완료 조건

- 로고, 타이틀, 플레이, 정지, 아이템 모드가 의도한 키 입력으로 전환된다.
- 아이템 선택과 공 발사가 요구사항대로 동작한다.
- `ESC` 입력으로 플레이 흐름에서 안전하게 종료 또는 타이틀 복귀가 가능하다.
